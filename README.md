# Old Norse Dictionary (Version 2.0)

An offline-first Progressive Web App (PWA) dictionary and grammar analyzer for Old Norse, styled in carved Viking-age oak knotwork.

**Live App:** [https://gjakkrdagnyjarson.github.io/Old-Norse-Dictionary/](https://gjakkrdagnyjarson.github.io/Old-Norse-Dictionary/)

## Installation (Offline PWA)

* **Android (Chrome):** Tap **⋮** → **Add to Home screen / Install app**.
* **iOS (Safari):** Tap **Share** → **Add to Home Screen**.
* **Windows / Mac / Chromebook (Chrome or Edge):** Click the **Install** icon in the address bar.

## Key Features

* **111,488 Old Norse Headwords** in authentic Old Norse alphabetical order (`A Á B D Ð E É F G H I Í J K L M N O Ó P R S T U Ú V Y Ý Þ Æ Ø Ǫ Œ`).
* **Reverse Inflected-Form Search:** Type conjugated verbs or declined nouns (e.g., *kattar*, *sérð*) to trace directly back to their root lemma.
* **39,374+ 4-Case Noun Declensions & Verb Conjugation Tables.**
* **Preposition Case Government (*Stjórn*) Cards:** Instant Accusative, Dative, and Genitive case rules for Old Norse prepositions (`af`, `frá`, `til`, `at`, `á`, `í`, `með`, `við`, etc.).
* **Sentence & Grammar Analyzer:** Built-in morphological breakdown and case-government checker.
* **Saved Bookmarks (★) & Viking-Age Younger Futhark Runes** for every headword, framed in custom carved oak artwork.
